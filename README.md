# Fresh Market

متجر بسيط مبني من تصميم Figma: صفحة متجر + نموذج طلب + صفحة مشرف.

- `server.js` الخادم (Express) و API
- `public/` الواجهة
- `public/images/` ضع هنا صور Figma المصدّرة: hero.jpg, pears.jpg, pears2.jpg, mushrooms.jpg, watermelon.jpg
- `data/orders.json` يُنشأ تلقائياً عند أول طلب

التشغيل: `npm install` ثم `npm start`
